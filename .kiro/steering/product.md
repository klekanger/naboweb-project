# Product Overview

Gartnerihagen Boligsameie v2.0 is a Norwegian housing cooperative website that serves as a digital platform for residents and board members.

## Core Features

- **Public Website**: Information about the housing cooperative, blog posts, and general content
- **Resident Portal**: Protected areas for logged-in residents with access to:
  - Board information and announcements
  - Message board for community discussions
  - Meeting minutes and documents
  - Document library with various file types
- **Content Management**: Sanity CMS integration for managing all content
- **User Management**: Clerk authentication with role-based access control
- **Email Notifications**: Automated email alerts for community updates

## Target Users

- **Residents**: Access community information, participate in discussions
- **Board Members**: Manage content, send announcements, moderate discussions
- **Public Visitors**: View general information about the housing cooperative

## Language

The application is primarily in Norwegian (nb-NO locale).
