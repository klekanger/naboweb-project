# Documentation & Learning Resources

## Context7 MCP Integration

Always use Context7 MCP to look up relevant documentation and examples when:

- Implementing new features with unfamiliar libraries
- Troubleshooting integration issues
- Learning best practices for the tech stack
- Finding code examples for specific use cases

## Priority Documentation Sources

1. **Next.js** - App Router patterns, Server Components, API routes
2. **Sanity** - Schema design, GROQ queries, content modeling
3. **Clerk** - Authentication flows, role management, Norwegian localization
4. **Tailwind CSS** - Utility classes, responsive design patterns
5. **HeroUI/NextUI** - Component API, theming, accessibility features

## When to Use Context7

- Before implementing complex integrations
- When encountering TypeScript errors with third-party libraries
- For performance optimization techniques
- When setting up testing patterns
- For accessibility implementation guidance

## Learning Approach

- Start with official documentation via Context7
- Prioritize recent examples (2024+) for latest API versions
- Cross-reference multiple sources for complex implementations
